# Sample HL7 v2 ADT feed — provenance

`adt_feed.hl7` was **authored for this repository**. The patients, MRNs, NPIs, visit numbers and
addresses are invented; none of it comes from a real feed, a real hospital or a real person.

Six messages, each present for a reason:

| Message | Event | What it exercises |
|---|---|---|
| `MSG00001` | A01 admit | full registration: name, sex, DOB, CDC race and ethnicity, address, inpatient class, attending doctor, admit time |
| `MSG00002` | A03 discharge | the same visit number as the A01, so the discharge time has to merge onto the encounter the A01 created rather than making a second one |
| `MSG00003` | A04 register outpatient | a different patient, ambulatory class, admit and discharge in one message |
| `MSG00004` | A08 update | corrects `MSG00003`'s birth date and adds a middle name — last write wins |
| `MSG00005` | A02 transfer | deliberately unsupported: must produce a warning and no resources, not a silent no-op |
| `MSG00006` | A01 admit | patient class `N` (no v3 ActCode) and no `PV1-44` admit time: both refusals, warned about individually |

Field positions follow HL7 v2.5.1. The file was generated by a script that places values by field
index rather than by counting pipes, because `PV1-44` is the forty-fourth field and hand-counting is
how ADT test fixtures end up subtly wrong.

Encoding characters are read from `MSH-2` rather than assumed, so a feed using non-default separators
parses correctly.
